截屏翻译 v0.1.0
================

一个 Windows 小工具：按热键框选屏幕区域，自动识别文字并翻译成中文，
结果显示在屏幕上的小卡片里。


一、怎么用
----------

1. 双击 ScreenshotTranslate.exe（会出现在右下角托盘，没有主窗口）
2. 第一次用要填 API Key：
   右键托盘图标 → 设置… → 填「API Key」→ 点「测试连接」→ 保存
3. 按 Alt+Q，屏幕会变暗
4. 按住左键拖出一个框，松开手
5. 等 1–2 秒，卡片出现：上面是原文，下面是译文

卡片上可以「复制译文」「重译」，右上角 ✕ 关闭。

找不到托盘图标？
Windows 11 默认会把新程序的图标收进任务栏的 ^ 折叠区里。
点一下 ^，把「译」图标拖到任务栏上；或者在「设置 → 个性化 → 任务栏 →
系统托盘图标」里把它打开。

也可以直接再双击一次 exe —— 程序不会重复启动，而是把设置窗口叫出来。

如果任务栏根本不显示第三方程序的托盘图标（某些精简系统 / 远程桌面 / 美化版
任务栏会这样），第一次启动时屏幕右下角会弹出一个提示小窗，点「打开设置」
就能用；之后每次都可以双击 exe 打开设置。


二、第一次运行会慢一点
----------------------

第一次识别需要加载 OCR 模型，大约 2–3 秒；之后每次 0.5 秒左右。
OCR 完全在本机跑，截图不会上传，只有识别出来的文字会发给翻译服务。


三、常见问题
------------

Q: 按 Alt+Q 没反应？
A: 热键被别的软件占了。右键托盘 → 设置 → 换一个组合（必须带 Ctrl/Alt/Shift）。

Q: 提示没有配置 API Key？
A: 右键托盘 → 设置，填好 Key 后点「测试连接」，能返回示例译文就说明通了。

Q: 怎么退出程序？
A: 双击 exe 打开设置，点左下角「退出程序」；有托盘图标时右键图标也能退出。
   任务管理器里结束 ScreenshotTranslate.exe 也可以。

Q: 杀毒软件报毒？
A: 未签名的 Python 打包程序常被误报。如果不放心可以自己从源码运行，
   或者把本目录加入白名单。

Q: 托盘图标不见了？
A: 多半是被 Windows 11 收进了 ^ 折叠区：点 ^ 展开，把「译」拖到任务栏上，
   或在「设置 → 个性化 → 任务栏 → 系统托盘图标」里打开。
   实在找不到，直接再双击一次 exe，会弹出设置窗口。

Q: 提示「没有识别到文字」？
A: 框大一点，或者对准文字再框一次；极小字号/极低对比度可能识别不到。

Q: 配置和日志在哪？
A: %APPDATA%\ScreenshotTranslate\（config.json 和 logs\app.log）


四、系统要求
------------

Windows 10 1903 及以上 / Windows 11，64 位。
不需要安装 Python，整个文件夹一起复制即可，路径不要有中文以外的特殊字符更稳妥。


五、卸载
--------

删除整个文件夹；如果要彻底清理，再删掉 %APPDATA%\ScreenshotTranslate。
